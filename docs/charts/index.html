Regenerating all of it

A stranger with this repository can reproduce every file on this page from a fresh dataset. Three things will differ, because they are wall-clock and file identity rather than data: the run id, the dataset's file name and digest, and the generated_at timestamp in each footer. Everything else is a function of the data.

python3 -m market_swarm run --config market_swarm/example-run.json --dry-run --kill-after 120 --out .swarm-runs
python3 tools/swarm_charts.py generate --out docs/charts \
    --dataset .swarm-runs/<run>-evt_capped-SYNTHETIC.jsonl \
    --dataset .swarm-runs/<run>-evt_monitored-SYNTHETIC.jsonl
python3 tools/swarm_charts.py verify --out docs/charts \
    --dataset .swarm-runs/<run>-evt_capped-SYNTHETIC.jsonl \
    --dataset .swarm-runs/<run>-evt_monitored-SYNTHETIC.jsonl

The last command is the one that checks the numbers: it rebuilds each series from the dataset and compares it with the series the asset recorded. Run as verify --out docs/charts with no --dataset, it checks the labels and the internal consistency of the files, says so, and exits 3 rather than claiming a pass.

docs/CHARTS.md is the written account: what each asset shows, the command that regenerates it, and the label rule the tool enforces on itself.

Nothing on this page is a finding about a real market. Every number on it is class E: synthetic, generated, and not evidence (records/findings/31).
